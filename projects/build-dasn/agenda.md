# Build DASN agenda

Updated: 2026-09-22. This is a proposed working order for the local preview.

1. **Review the project tiles.** Done when the localhost view reads clearly at desktop and mobile sizes and distinguishes real projects from examples.
2. **Choose initial real projects.** Done when each candidate has a purpose, bounded first outcome, and public-safe description approved by Josiah.
3. **Try the project-file convention with one real collaboration.** Done when the scope, current state, and agenda files help a contributor orient and record an actual result.
4. **Run a separate-contributor review.** Done when a useful contribution is independently reviewed, the outcome is recorded, and remaining friction is named.

## Decisions needed

- Which projects to seed, if any, after Build DASN — Josiah.
- Whether new projects should automatically receive three workspace files — Josiah and the project's members, informed by the pilot.
- Whether and when to publish the tile design and file convention — Josiah.
